B&S Store - E-Ticaret Platformu (Staj Projesi)
D&R platformundan Selenium ile çekilen verilerin MSSQL'e aktarıldığı, .NET Minimal API servisleri ile sunulduğu ve iyzico sanal POS altyapısıyla tamamlandığı full-stack e-ticaret uygulaması.

🚀 Kullanılan Teknolojiler
Web Scraping: C# / Selenium WebDriver

Backend: C# .NET Minimal API

Veritabanı: Microsoft SQL Server (Stored Procedures & T-SQL)

Ödeme Entegrasyonu: iyzico Checkout Form (Sandbox)

Frontend: HTML5, CSS3, JavaScript (ES6+, Fetch API, LocalStorage)

📌 Öne Çıkan Özellikler
Veri Madenciliği: D&R (Kitap, Elektronik, Hobi, Kırtasiye) ürün verilerinin dinamik kazınması ve veritabanına aktarımı.

Arama & Filtreleme: Stored Procedure destekli anlık ürün/kategori/yazar araması.

Sepet & Baremli Kargo: LocalStorage tabanlı sepet yönetimi ve tutara göre kargo baremi hesaplayan progress bar.

Güvenli Ödeme: iyzico API ile token tabanlı form başlatma ve callback ile sipariş kaydı.

Kullanıcı & Sipariş: Profil/adres yönetimi, sipariş geçmişi ve durum simülasyonu (iptal/iade).
